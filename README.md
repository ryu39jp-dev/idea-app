# 🏗️ AI Trend Architect

トレンド分析から紐解くアプリ仕様ジェネレーター。

PerplexityやChatGPTなどの他AIが出力した「今話題の不満・トレンド分析」をそのまま貼り付けるだけで、
**①プロダクトの核心アイデア → ②技術スタック＆構造設計書 → ③AIコーディングエージェント向けの実装指示プロンプト**
を段階的に生成します。

---

## 仕組み（3段階フロー）

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  [トレンド分析テキストを貼り付け]                                │
│         ↓ clean_trend_text でノイズ除去（コスト削減）           │
│  [① プロダクトの核心アイデアを生成]                              │
│         ↓ 気に入らなければ指摘 → 再生成（①のみ）を繰り返す       │
│  [✅ このアイデアで確定]                                         │
│         ↓                                                    │
│  [② 最適技術スタック ＆ 自動生成用構造設計書を生成]                │
│         ↓                                                    │
│  [③ AIコーディングエージェント向け実装指示プロンプトを生成]         │
│         ↓                                                    │
│  [Claude Code / Cursor 等にそのまま貼り付けて開発開始]            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

①は何度でも無料に近いコストで再生成・修正できますが、②③は「①が確定した後」に
ボタンを押した時だけ生成されます。①を変更すると②③は自動的にリセットされ、
古い内容と食い違ったまま残ることはありません。

## 画面構成

アプリ内は3つのタブで切り替えます（生成済みのものだけ表示されます）：

| タブ | 内容 |
|------|------|
| 💡 ① アイデア | プロダクトの核心アイデア。指摘を入力して何度でも再生成可能 |
| 🛠️ ② 技術設計書 | 最適な技術スタックの選定＋データ構造・アルゴリズム・実装方針 |
| 🤖 ③ AI実装指示 | Claude Code等にそのまま貼り付けられる実装指示プロンプト |

各タブの出力は `.md` ファイルとしてダウンロードできます。

## セットアップ

### 1. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. AWS側の準備

#### ① IAMユーザーにBedrockの権限を付与

IAMポリシーに以下のアクションを許可してください：

```json
{
  "Effect": "Allow",
  "Action": [
    "bedrock:InvokeModel",
    "bedrock:InvokeModelWithResponseStream"
  ],
  "Resource": "*"
}
```

#### ② Bedrockでモデルアクセスを有効化

AWSコンソール → **Amazon Bedrock** → **モデルアクセス** →
`Claude Haiku 4.5` を選択して **アクセスをリクエスト**

> ほとんどのモデルは即時承認されます。リージョンは `ap-southeast-2`（Sydney）を選択してください。

### 3. 環境変数の設定

```bash
cp .env.example .env
```

`.env` を開いて以下を入力：

```env
AWS_ACCESS_KEY_ID=AKIAxxxxxxxxxxxxxxxxxxxx
AWS_SECRET_ACCESS_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
AWS_DEFAULT_REGION=ap-southeast-2
BEDROCK_MODEL_ID=anthropic.claude-haiku-4-5-20251001-v1:0
```

### 4. アプリを起動

```bash
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。

## 使い方

1. PerplexityやChatGPTなどに「今XやYouTubeで話題の不満・トレンド」を調べさせる
2. その出力結果をテキストエリアにそのまま貼り付ける（ハッシュタグ・URL・絵文字は自動除去されます）
3. **「🚀 ① 核心アイデアを生成する」**を押す
4. 気になる点があれば、緑のパネルに指摘を書いて**「🔄 この指摘を反映して再生成する」**
   - 何度でも繰り返せます。過去バージョンは「🕑 過去バージョンを見る」から確認可能
5. 納得したら**「✅ このアイデアで確定し、技術設計書を生成する」**を押す → ②が生成される
6. ②のタブから**「🤖 ③ AI実装指示プロンプトを生成する」**を押す → ③が生成される
7. ③の内容をコピーして、Claude CodeやCursorなどのAIコーディングエージェントに貼り付けて開発開始

## 設計のポイント

### コスト最適化（`clean_trend_text`）

ユーザーが貼り付けたトレンドテキストは、Bedrockに送信する前に以下を自動除去してトークン数を削減します：

- URL（`https?://...`）
- Xのハッシュタグ（`#xxx`）・メンション（`@xxx`）
- 絵文字・装飾記号
- 連続する空白行

クリーニング前後の文字数・削減率は画面上に表示されます。

### ①②③ の分離生成

①は「アイデアを練る」フェーズなので、何度再生成してもコストが小さく済むように
1回あたりの出力を絞っています（`max_tokens=2048`）。
②③は①確定後の1回だけ生成されるため、詳細な設計書として`max_tokens=4096`で出力します。

①を再生成・新規生成すると②③は自動的に破棄され、内容の食い違いを防ぎます。

### 「AI丸投げ」アイデアの排除

システムプロンプトには、「AIチャットボット」のような薄いアイデアを避け、
トレンドの不満を的確に解決する実用的なプロダクトを提案するよう明記しています。

### ③ 実装指示プロンプトの方針

③で生成されるプロンプトには、以下が必ず明記されます：

- 無料枠で動くホスティング・DB構成を優先（Streamlit Community Cloud / SQLite 等）
- LLM API呼び出しの最小化・キャッシュ・トークン上限の指定
- ファイル構成・各ファイルの責務・実装の優先順位
- エラーハンドリング・環境変数管理の方針

## モデルの変更

`.env` の `BEDROCK_MODEL_ID` を書き換えるだけで切り替えられます：

```env
# 高速・低コスト（デフォルト）
BEDROCK_MODEL_ID=anthropic.claude-haiku-4-5-20251001-v1:0

# より高精度にしたい場合
BEDROCK_MODEL_ID=anthropic.claude-sonnet-4-5-20251001-v1:0

# 旧世代（モデルアクセスが通らないときの代替）
BEDROCK_MODEL_ID=anthropic.claude-3-haiku-20240307-v1:0
```

## AWS認証なしでの動作確認

AWS認証情報が未設定の場合、自動的に**ダミーデータモード**で起動します（画面に🔴DEMOバッジが表示）。
①②③ともにダミー出力で、UIのレイアウトや操作フローの確認に使えます。

---

## トラブルシューティング

| エラー | 原因 | 対処 |
|--------|------|------|
| `AccessDeniedException` | IAM権限不足 or モデルアクセス未申請 | AWSコンソールでモデルアクセスをリクエスト |
| `ResourceNotFoundException` | モデルIDが間違っている | `.env` の `BEDROCK_MODEL_ID` を確認 |
| `ThrottlingException` | リクエスト過多 | 少し待ってから再試行 |
| AWS認証情報が読まれない | `.env` の場所が違う | `app.py` と同じディレクトリに `.env` を置く |
| ②③のセクションが見つからない | 出力がトークン上限で途中で切れた | `llm_client.py` の `max_tokens` を増やす |
